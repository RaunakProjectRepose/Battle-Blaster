# Battle Blaster

Battle Blaster is a 3D tank combat game developed using Unreal Engine 5 and C++ as part of the GameDev.tv Unreal Engine 5 C++ game development course.

The project explores vehicle gameplay, projectile-based combat, enemy behavior, and user interface development in Unreal Engine.

## Project Overview

- **Engine:** Unreal Engine 5
- **Language:** C++
- **Genre:** Tank Combat
- **Project Type:** Course-based learning project
- **Course:** Unreal Engine 5 C++ Game Development — GameDev.tv

## Core Gameplay

The game focuses on controlling a tank, engaging enemy vehicles, and using projectile combat to survive encounters.

## Learning Objectives

- Implementing gameplay logic in C++
- Working with vehicle movement and controls
- Creating and handling projectiles
- Implementing enemy combat behavior
- Using collision detection and hit events
- Building a gameplay HUD
- Integrating C++ classes with Unreal Engine assets

## Technologies

- Unreal Engine 5
- C++
- Unreal Engine Editor
